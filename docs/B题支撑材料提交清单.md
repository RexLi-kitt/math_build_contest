# B题支撑材料提交清单

依据 `比赛题目/B题/B题.pdf` 与 `比赛题目/format2026.doc` 整理。

## 一、题目明确要求

1. 问题3完成三次正式测试，在论文表1中填写每次的案例编码、清除干扰源个数、平均定位清除时间、程序运行时间。
2. 问题3从模拟器导出三次正式测试的加密行为日志，不修改文件名，放入支撑材料。
3. 问题4完成三次正式测试，按同一张表1填写四项结果。
4. 问题4从模拟器导出三次正式测试的加密行为日志，不修改文件名，放入支撑材料。

平均定位清除时间按题目定义为：定位清除总虚拟时间 / 被清除干扰源个数。

## 二、通用格式规范明确要求

1. 支撑材料至少包含建模使用的全部完整、可运行源程序。
2. 包含自主查阅并实际使用的数据资料；赛题提供的原始数据无需重复提交。
3. 包含正文放不下、但用于支撑模型、结果和结论的大篇幅中间结果、图表或数据。
4. 所有材料压缩为一个 RAR 或 ZIP 文件，大小不超过 20 MB。
5. 论文附录必须列出支撑材料文件清单，并附建模使用的全部完整、可运行源程序代码。
6. 支撑材料与论文中的模型、参数、统计结果和版本必须一致。
7. 支撑材料不得包含承诺书、编号专用页、队员姓名、学校或赛区等身份信息。

## 四、源程序最低组成

- 问题1：论文中定位区域、直径与反例计算所用全部脚本及运行说明。
- 问题2：候选点生成、评分、权重校准、独立验证和论文制图所用脚本。
- 问题3：J+最终代理、官方接口入口、离线模拟器、主对比/消融/鲁棒性脚本，以及运行依赖与固定随机种子说明。
- 问题4：`d_agent.py`、`official_d_runner.py`、`q4_routes.py`、`assets/d_model/` 两个设计文件，以及D验证、鲁棒性和结果汇总脚本。
- 论文中出现的所有数值表和图，均应能由所交代码和数据重新生成。

## 五、建议保留的结果材料

- 各问最终模型的聚合指标、消融结果和鲁棒性汇总；正文引用置信区间时保留对应逐案例数据或足以复算的统计文件。
- 问题3三次与问题4三次正式测试的结果汇总表。
- 问题4的D模型数学公式、认证站点设计文件、覆盖验证和距离门零漏检审计。
- 官方接口本地明文动作日志可作为额外审计材料，但只能作为补充，不能替代模拟器导出的加密日志。

## 六、不建议放入

- 赛题PDF、赛题原始附件和模拟器安装包。
- 未在论文中使用的大量历史失败版本、重复缓存、临时文件、解释器环境和参考论文全文。
- 含队员姓名、学校、赛区或其他身份信息的文件。
- 与最终论文口径不一致的旧模型结果。
