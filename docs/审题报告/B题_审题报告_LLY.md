# B题 无线电干扰源的快速自动定位与清除 审题报告

## 一 这是什么类型的题目 每一问要交付什么

### 1 总体题型

这是一道“**定位算法 + 搜索策略 + 路径规划 + 模拟器测试**”综合题。


### 2 各问任务和交付物

| 问题 | 题目类型 | 要解决的事情 | 最后需要交付什么 |
|---|---|---|---|
| 问题1 | 几何计算与算法题 | 根据多个检测点和测得的方向，画出干扰源可能所在的多边形区域，并计算该区域最远两点间的距离 | 定位区域的构造方法、区域直径的计算算法；回答“直径相同的圆能否覆盖该区域” |
| 问题2 | 检测点选择题 | 研究第二个点应该选在哪里 | “定位效果好”的评价标准、第二检测点选择规则、候选区域图或示意图 |
| 问题3 | 搜索与优化题 | 机器狗要把全部干扰源找出、定位并清除，同时尽量节省时间 | 完整搜索和清除流程、算法流程图、演练测试结果、三次正式测试结果表、三份正式测试日志 |
| 问题4 | 定向干扰源条件下的改进题 | 部分干扰源只向某一半方向发射信号，机器狗可能在某些位置完全收不到信号，需要改进问题3的策略 | 改进后的检测与清除策略、算法、演练结果、三次正式测试结果表、三份正式测试日志 |



## 二 各问之间可以复用什么

| 可复用内容 | 在哪一问建立 | 后续怎么用 |
|---|---|---|
| 根据检测方向得到扇形范围 | 问题1 | 问题2、3、4每次检测后都要使用 |
| 多个扇形求交并计算定位区域大小 | 问题1 | 问题2评价第二检测点，问题3、4判断是否定位准确 |
| 第二检测点选择方法 | 问题2 | 问题3、4发现信号后继续定位 |
| 频道状态记录 | 问题3 | 问题4在此基础上增加定向源判断 |
| 搜索路线和清除顺序 | 问题3 | 问题4可以继续使用，只需增加检测点 |
| 时间计算方法 | 问题3 | 问题4完全相同 |
| 模拟器通信程序和日志记录 | 问题3 | 问题4完全复用 |
| 演练测试统计方法 | 问题3 | 问题4使用相同指标，方便比较 |



## 三 哪些问题存在真正的前后依赖

本题的主要关系是：

> 问题1解决“怎样根据多次检测确定位置范围”  
> 问题2解决“下一次应该去哪里检测”  
> 问题3解决“怎样把搜索、定位、赶路和清除组合成完整流程”  
> 问题4解决“遇到定向干扰源时，怎样避免漏检”

具体依赖如下：

- **问题2依赖问题1**：要比较哪个第二检测点更好，就要用问题1的方法计算定位区域大小。
- **问题3依赖问题1和问题2**：发现信号后需要交会定位，也需要选择新的检测点。
- **问题4依赖问题3**：问题3中的频道管理、路线规划、时间计算、清除方法和程序接口都可以保留，只改进搜索和判断无信号的部分。
- **问题1最后的圆覆盖结论也会影响问题3、4**：即使定位区域直径不大，也不能直接认为区域中心一定能清除成功。建模手需要找一个点，使定位区域内任何可能位置到该点的距离都不超过 20 米。

## 四 全文应该讲出什么逻辑链

建议论文按照下面的顺序展开：

1. 说明题目场景、已知条件和时间规则；
2. 把正负 1 度测向误差表示成扇形范围；
3. 建立多次检测后的定位区域计算方法；
4. 研究第二检测点的位置如何影响定位精度；
5. 设计全向干扰源的全区域搜索方法；
6. 对发现的干扰源进行继续定位，并安排清除顺序；
7. 统计演练测试的清除比例和时间；
8. 针对定向干扰源增加多方向检测和外圈检测；
9. 比较改进前后的清除率与时间；
10. 给出两问的三次正式测试结果和日志说明。

全文可以围绕一条简单主线来写：

> 先通过覆盖搜索保证不漏掉目标，再通过多点测向缩小位置范围，最后通过路线优化减少移动和检测时间。


## 五 每一问需要哪些证据支撑

### 1 问题1

建议准备：

- 一张交会定位示意图；
- 一个完整算例，展示多个扇形如何形成定位区域；
- 算法流程或伪代码；
- 一个说明“直径相同的圆不一定能覆盖区域”的反例图；
- 对方向接近平行、角度跨越 0 度等特殊情况的测试。

本问最重要的证据是**几何图、算法步骤和反例**，不一定需要大量统计图。

### 2 问题2

建议准备：

- 第一次检测扇形和第二检测点候选区域图；
- 不同第二检测点对应的定位区域大小对比表；
- 交会角与定位误差的关系图；
- 随机选点、垂直方向选点和本文策略的对比；
- 改变方向误差、接收距离后，结果是否仍然稳定的敏感性分析。

本问最好让图表直接说明：为什么某一片区域适合作为第二检测点，而不是只写经验判断。

### 3 问题3

建议准备：

- 检测点覆盖圆形目标区域的示意图；
- 一次典型演练的机器狗运动轨迹图；
- 搜索、定位和清除的程序流程图；
- 多次演练的结果统计表；
- 清除比例达到 100% 的测试记录；
- 总时间或平均时间的均值、最大值、最小值和标准差；
- 移动、频道切换、检测、清除分别占多少时间的时间构成图；
- 有无第二点优化、有无路线优化的对比实验；
- 干扰源数量从 10 个增加到 16 个时的时间变化图；
- 三次正式测试结果表和三份正式日志。

本问不应只展示一次成功案例。应使用多次演练说明策略既能清除全部目标，又具有比较稳定的用时。

### 4 问题4

除问题3的图表外，建议增加：

- 全向源和定向源的信号覆盖示意图；
- 从不同方向检测同一个定向源的示意图；
- 只在圆内检测与增加圆外检测的结果对比；
- 全向源、定向源分别被发现和清除的数量；
- “一次无信号就判断不存在”与“多位置检查后再判断”的漏检率对比；
- 定向源数量、发射方向、有效接收距离变化时的敏感性分析；
- 搜索点增加后，清除率提高了多少、时间增加了多少的对比图；
- 三次正式测试结果表和三份正式日志。

问题4最重要的是证明：新增的多方向检测确实降低了定向源漏检风险，而且增加的时间仍然可以接受。
