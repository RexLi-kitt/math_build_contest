# Q1 任务卡：交会定位区域与直径计算

作者：李培煜（lpy）

## 一、问题定性与目标

本问是计算几何问题。利用示向度的 ±1° 误差构造楔形区域，逐次求交得到干扰源的可行位置集合，再计算区域内最远两点的距离。

需要交付：定位区域构造方法、凸性与直径公式的证明、可实现的算法，以及同直径圆能否覆盖区域的结论和反例。

记干扰源为 G，检测点为 S_i，避免混淆待定位目标和检测点。

## 二、数据与基本假设

| 符号 | 含义 | 约定 |
|---|---|---|
| S_i=(x_i,y_i) | 第 i 个检测点坐标 | 单位：米 |
| θ̂_i | 对同一干扰源测得的有效示向度 | 从正东逆时针计量，单位：度 |
| ε | 示向度误差上界 | 1° |
| W_i | 第 i 条观测对应的闭楔形区域 | 张角 2° |
| P | 所有楔形的交集 | 交会定位区域 |
| v_0,…,v_(m−1) | 定位多边形顶点 | 逆时针排列 |
| D | 定位区域直径 | 单位：米 |

1. 干扰源在观测期间固定，检测点与干扰源视为同一平面内的点，检测点坐标准确已知。
2. 每条有效示向度与真实方位的圆周角度偏差不超过 1°。这是确定性误差界，不需要额外假设误差独立或服从某种概率分布。
3. 同一地点重复检测不改变误差，不能通过重复测量取平均来缩小角度带。
4. 只使用同一频道、同一干扰源的有效示向度。“无信号”或距离过近导致无法测向的记录不作为角度输入；近距离清除由后续问题处理。
5. 正常交会分支针对非空、有界且具有正面积的交集，但算法必须识别空集、无界和退化情形，不能假定任意检测点组合都能得到多边形。

本问以楔形求交形成的多边形为研究对象。半径 1800 米的目标圆域可作为后续实际定位的额外先验，但主算法不进行圆域裁剪：裁剪后可能出现圆弧，不能直接使用仅检查多边形顶点的直径算法。这里求的是基于角度信息的保守定位区域，不额外加入距离约束。

## 三、将角度带转化为半平面

定义二维叉积

\[
\operatorname{cross}(a,b)=a_xb_y-a_yb_x.
\]

第 i 条观测的两侧边界方向为

\[
u_i^-=(\cos(\hat\theta_i-\varepsilon),\sin(\hat\theta_i-\varepsilon)),\qquad
u_i^+=(\cos(\hat\theta_i+\varepsilon),\sin(\hat\theta_i+\varepsilon)).
\]

三角函数计算前将角度转换为弧度。对候选点 X=(x,y)，其可行楔形为

\[
W_i=\{X:\operatorname{cross}(u_i^-,X-S_i)\ge0,
\ \operatorname{cross}(u_i^+,X-S_i)\le0\}.
\]

两个不等式分别要求点位于下侧边界的左侧和上侧边界的右侧。由于张角仅为 2°，它们共同选出朝向干扰源的楔形，不会把反方向也包含进去。向量表达自然处理角度跨越 0°/360° 的情况。

采用包含楔形顶点的闭集表示。检测点本身的方位角无定义，但将其保留在几何闭集中仍能保证模型包含真实位置；检验时不要在零向量上计算方位角。

定位区域为

\[
P=\bigcap_{i=1}^{n}W_i=\{X:AX\le b\}.
\]

这里共有 2n 个半平面。逐次加入观测相当于 P_k=P_(k−1)∩W_k，所以区域只会缩小或保持不变。

## 四、为什么定位区域是凸多边形

每个半平面都是凸集，每个楔形是两个半平面的交，因此也是凸集。有限个凸集的交仍为凸集，所以 P 是凸集。

P 由有限个线性不等式定义。当它非空、有界且具有正面积时，就是凸多边形；退化时可能是线段或单点。

因此，原方案中的“得到的一定是凸包”应改成“在上述条件下得到凸多边形”。取得顶点后，才可写成

\[
P=\operatorname{conv}\{v_0,\ldots,v_{m-1}\}.
\]

## 五、如何构造定位多边形

### 1. 先检查可行性和有界性

对 AX≤b 做线性规划可行性检查。不可行则输出“空集”，排查观测对应、角度单位、坐标或误差界，不能擅自放宽误差界。

若可行，分别最大化 x、−x、y、−y。四个目标都有有限最优值，当且仅当区域有界；若任一目标无界，则纯角度交会未形成有限区域，返回“无界，需增加有效观测”。

不能随意加一个很大的初始矩形，然后把截断后的直径当作原区域直径。

### 2. 少量观测的基础实现：枚举边界交点

1. 构造全部边界直线及其半平面约束。
2. 枚举非平行边界直线对并计算交点。
3. 将交点代入全部约束，仅保留满足所有半平面的点。
4. 对保留点去重并求凸包，得到逆时针顶点序列，删除共线边上的冗余中间点。
5. 根据结果判断为多边形、线段或单点。

完整性依据：非空有界多面体的每个顶点都由至少两条线性无关的有效边界约束确定，因此枚举不会漏掉顶点。

共有 O(n²) 对边界，每个交点检查 O(n) 条约束，构造部分复杂度为 O(n³)，不含前面的线性规划检查。观测较少时，这一方法便于实现和验证。

观测较多时可改用按方向排序的半平面交算法，常见实现复杂度为 O(n log n)。已经取得有界多边形后，新增观测可通过两次半平面裁剪完成增量更新。

### 3. 数值注意事项

- 平行或重合直线不能直接用除法求交；近乎平行时可能需要提高精度，不能直接丢弃所有小交角。
- 分别设置半平面残差、坐标去重和面积判断的容差，记录容差及单位。
- 浮点容差不等同于放宽题目规定的 1° 误差界。
- 已判定非空有界却没有可靠顶点时，应报告数值失败，不能重新解释为空集。

## 六、区域直径及其算法

### 1. 为什么只需检查顶点

对任意 p,q∈P，存在顶点凸组合

\[
p=\sum_i\alpha_i v_i,\qquad q=\sum_j\beta_jv_j,
\quad\alpha_i,\beta_j\ge0,\quad\sum_i\alpha_i=\sum_j\beta_j=1.
\]

由三角不等式，

\[
\|p-q\|
=\left\|\sum_{i,j}\alpha_i\beta_j(v_i-v_j)\right\|
\le\sum_{i,j}\alpha_i\beta_j\|v_i-v_j\|
\le\max_{i,j}\|v_i-v_j\|.
\]

顶点本身属于区域，所以

\[
\boxed{D=\max_{i<j}\|v_i-v_j\|}.
\]

### 2. 基础算法与旋转卡壳

顶点少时，枚举所有顶点对，比较距离平方，最后开平方，复杂度 O(m²)。同时返回最远点对 a,b，便于作图。

顶点多时，使用旋转卡壳：沿逆时针边序列移动一侧支撑线，以叉积面积比较推进对侧支撑点，检查相关对踵顶点对的距离。对侧指针只需绕行一周，复杂度 O(m)。若相邻对侧顶点面积相等，应同时检查这些候选点，避免平行支撑边情况下漏检。

先实现全顶点对枚举作为参考，再验证旋转卡壳。这样既保留原方案的高效算法，也有容易核对的基础版本。

### 3. 完整流程伪代码

```text
输入：有效观测 (S_i, theta_i)，误差界 epsilon=1°
构造半平面组 AX≤b
若约束不可行：返回 EMPTY
若任一坐标方向无界：返回 UNBOUNDED，D=+∞

C = 空集合
枚举非平行边界直线对：
    计算交点 X
    若 X 满足所有半平面：加入 C
V = ConvexHull(去重(C))
若没有可靠顶点：返回 NUMERICAL_FAILURE
若为单点：D=0
若为线段：D=两端点距离
若为多边形：枚举顶点对或旋转卡壳，得到 D 和最远点对 a,b
返回区域类型、有序顶点、D、最远点对
```

空集不作为正常定位结果返回直径。单点和线段虽面积为零，仍是合法退化结果，不能把“面积大于零”作为所有非空区域的判据。

## 七、同直径圆能否覆盖定位区域

### 1. 结论：不一定能覆盖

边长为 D>0 的等边三角形，区域直径为 D，最小外接圆半径为

\[
R_{\min}=\frac{D}{\sqrt3}>\frac D2.
\]

所以任何直径为 D 的圆都无法覆盖该三角形。

该反例也能由楔形交会形成：在每条边的延长线上、越过一个端点足够远处放置检测点，让一条楔形边界沿该边指向三角形，另一条边界向内部旋转 2°。检测点足够远时，整个三角形都落在楔形内。三个楔形各提供一条三角形边界，它们的交就是该三角形。整体缩放可适配场景的长度尺度。

相反，矩形可以被以其对角线为直径的圆覆盖。因此应写“不一定能覆盖”，不能写成“一定不能覆盖”。

### 2. 给定多边形的直接判定

取一对最远点 a,b，距离为 D。若半径为 D/2 的圆包含它们，则圆心必须是 c=(a+b)/2。因为

\[
D=\|a-b\|\le\|a-c\|+\|c-b\|\le D,
\]

等号迫使 a,b 成为直径端点。

所以只需检查

\[
\boxed{\max_i\|v_i-c\|\le D/2.}
\]

圆盘为凸集，包含所有顶点就包含整个多边形。若有顶点超出，则不存在其他圆心能使同直径圆覆盖该区域。单点单独按半径为零处理；数值计算需注明比较容差。

### 3. 对后续问题的用途

第一问无需计算最小外接圆就能完成上述回答。后续若要选择保证清除的位置，可计算最小外接圆中心 c* 和半径 R_min；当 R_min≤20 米时，在 c* 处能够覆盖全部候选位置。

仅凭 D≤40 米不能保证存在这样的清除点。

## 八、结果检验

本问以几何证明和算法验证为主，不需要堆叠统计实验，但也不能认为“没什么好检验的”。

| 检验 | 方法与预期结果 |
|---|---|
| 已知真值算例 | 先设源点与检测点，再由真实方位加入不超过 ±1° 的误差；真值应满足全部约束，有界时位于输出区域内 |
| 顶点约束 | 全部顶点满足全部半平面，残差在记录的容差内 |
| 直径交叉验证 | 全顶点对枚举与旋转卡壳结果一致；等长最远点对允许不同 |
| 跨零角度 | 接近 0°/360° 的观测不应导致区域跳变或反向 |
| 特殊构型 | 检验空集、无界、单点、线段、平行及近乎平行边界，返回正确状态 |
| 输入不变性 | 打乱顺序或增加完全重复的观测，区域和直径不变 |
| 增加观测 | 增加一致观测后，新区域包含于旧区域；非空有界时直径不增 |
| 误差界敏感性 | 固定观测，依次取 0.9°、1.0°、1.1°，区域逐渐扩大；非空有界时直径不减 |
| 圆覆盖 | 等边三角形不通过，矩形通过 |

随机算例用于排查实现问题，不替代数学证明。误差在规定界内时，真值理论上必然满足角度约束；漏真值应排查程序和数值处理，不能解释为正常概率现象。同一地点的重复观测应复用同一误差。
