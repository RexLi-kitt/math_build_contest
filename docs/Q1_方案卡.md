# Q1 方案卡：示向度交会定位区域、区域直径与同直径圆覆盖

本卡是 Q1 的**唯一口径**。论文、代码（`src/q1`）与结果（`outputs/q1`、`src/q1/results`）均以本卡为准。

## 一、问题定性与目标

本问是计算几何问题。利用示向度的 ±1° 误差构造楔形区域，逐次求交得到干扰源的可行位置集合（定位区域），再计算区域内最远两点的距离（区域直径 D）。

需要交付三件事：

1. 定位区域的构造方法与凸性说明；
2. 区域直径的计算方法与最远点对；
3. 「以区域直径 D 为直径的圆」能否覆盖定位区域的结论及反例。

## 二、数据与基本假设

| 符号 | 含义 | 约定 |
|---|---|---|
| S=(x_S,y_S) | 干扰源（待定位目标，真实位置） | 单位：米 |
| M_i=(x_i,y_i) | 第 i 个检测点坐标 | 单位：米，坐标准确已知 |
| θ̂_i | 对同一干扰源测得的有效示向度 | 从正东逆时针计量，单位：度 |
| ε | 示向度误差上界 | 1° |
| W_i | 第 i 条观测对应的闭楔形区域 | 张角 2ε |
| P | 所有楔形的交集，即交会定位区域 | |
| v_0,…,v_(m−1) | 定位多边形顶点 | 逆时针排列 |
| D | 定位区域直径 | 单位：米 |

1. 干扰源在观测期间固定；检测点与干扰源视为同一平面内的点；检测点坐标准确已知。
2. 每条有效示向度与真实方位的圆周角度偏差不超过 1°。这是确定性误差界，不需要额外假设误差独立或服从某种概率分布。
3. 同一地点重复检测不改变误差，不能通过重复测量取平均来缩小角度带。
4. 只使用同一频道、同一干扰源的有效示向度。「无信号」或距离过近导致无法测向的记录不作为角度输入；近距离清除由后续小问处理。
5. 正常分支针对非空、有界且具有正面积的交集，但算法必须识别空集、无界和退化情形，不能假定任意检测点组合都能得到多边形。

**关于 1800 m 目标圆域**：本问求的是基于角度信息的保守定位区域，**主算法不引入距离约束、不裁圆域**。原因是圆域裁剪会在区域边界上产生圆弧，只检查多边形顶点的直径算法随之失效。1800 m 圆域在本问仅作为实验抽样的分布范围出现，作为实际定位先验留在后续小问使用。

## 三、将角度带转化为半平面

定义二维叉积 cross(a,b)=a_x·b_y−a_y·b_x。

第 i 条观测的两侧边界方向为

```
u_i⁻ = (cos(θ̂_i−ε), sin(θ̂_i−ε))
u_i⁺ = (cos(θ̂_i+ε), sin(θ̂_i+ε))
```

三角函数计算前将角度转换为弧度。对候选点 X=(x,y)，其可行楔形为

```
W_i = { X : cross(u_i⁻, X−M_i) ≥ 0,  cross(u_i⁺, X−M_i) ≤ 0 }
```

两个不等式分别要求点位于下侧边界的左侧和上侧边界的右侧。由于张角仅为 2°，它们共同选出朝向干扰源的楔形，不会把反方向也包含进去。向量表达自然处理角度跨越 0°/360° 的情况。

采用包含楔形顶点的闭集表示：检测点本身的方位角无定义，但将其保留在几何闭集中仍能保证模型包含真实位置；检验时不在零向量上计算方位角。

定位区域为

```
P = ∩ W_i = { X : A·X ≤ b }
```

共有 2n 个半平面。逐次加入观测相当于 P_k = P_(k−1) ∩ W_k，所以区域只会缩小或保持不变。

## 四、为什么定位区域是凸集

每个半平面都是凸集，每个楔形是两个半平面的交，因此也是凸集。有限个凸集的交仍为凸集，所以 P 是凸集。

P 由有限个线性不等式定义。当它非空、有界且具有正面积时，就是凸多边形；退化时可能是线段或单点。因此取得顶点后才可写成 P = conv{v_0,…,v_(m−1)}，不能笼统地说「得到的一定是凸包」。

## 五、如何构造定位多边形

### 1. 先检查可行性和有界性

不可行则输出「空集」，排查观测对应、角度单位、坐标或误差界，**不擅自放宽误差界**。

可行时检查是否存在无界方向：区域无界等价于存在非零方向 d 使全部法向满足 n·d ≤ 0。存在这样的 d 就是「无界，需增加有效观测」，返回无界状态并给出一个可行点与一个非零延伸方向。

代码采用「枚举交点 + 衰退方向判定」实现这两项检查，而非调用线性规划求解器；两者目的一致，实现路径不同。不得人为加一个很大的初始矩形，再把截断后的直径当作原区域直径。

### 2. 少量观测的基础实现：枚举边界交点

1. 构造全部边界直线及其半平面约束；
2. 枚举非平行边界直线对并计算交点；
3. 将交点代入全部约束，仅保留满足所有半平面的点；
4. 对保留点去重并求凸包，得到逆时针顶点序列，删除共线边上的冗余中间点；
5. 根据结果判断为多边形、线段或单点。

完整性依据：非空有界多面体的每个顶点都由至少两条线性无关的有效边界约束确定，因此枚举不会漏掉顶点。共有 O(n²) 对边界，每个交点检查 O(n) 条约束，构造部分复杂度为 O(n³)，观测较少时便于实现与验证。

### 3. 数值处理

- 平行或重合直线不能直接用除法求交；近乎平行时也不直接丢弃。
- 几何运算（半平面包含、去重、凸包、覆盖判定）全部用有理数精确比较，不设浮点容差，不因数值大小裁掉狭长区域。
- 角度转方向向量仍需三角函数，因此极端临界构型可能受舍入影响，这是已知限制。
- 已判定非空有界却没有可靠顶点时报告数值失败，不重新解释为空集。

## 六、区域直径及其算法

### 1. 为什么只需检查顶点

对任意 p,q ∈ P，存在顶点凸组合 p = Σ α_i v_i、q = Σ β_j v_j（α_i,β_j ≥ 0 且各自求和为 1）。由三角不等式

```
‖p−q‖ = ‖Σ_{i,j} α_i β_j (v_i−v_j)‖ ≤ Σ_{i,j} α_i β_j ‖v_i−v_j‖ ≤ max_{i,j} ‖v_i−v_j‖
```

顶点本身属于区域，所以

```
D = max_{i<j} ‖v_i − v_j‖
```

### 2. 两种算法互相验证

- **全顶点对枚举**：比较距离平方，最后开平方，复杂度 O(m²)，同时返回最远点对 a,b。
- **旋转卡壳**：沿逆时针边序列移动一侧支撑线，以叉积面积比较推进对侧支撑点，对侧指针只绕行一周，复杂度 O(m)。相邻对侧顶点面积相等时同时检查这些候选点，避免平行支撑边漏检。

实现以旋转卡壳为默认，并以全顶点对枚举作为参照，两法所得距离平方要求**精确一致**。

### 3. 特殊情况

空集不作为正常定位结果返回直径；单点和线段虽面积为零，仍是合法退化结果，不能把「面积大于零」当作所有非空区域的判据。

## 七、同直径圆能否覆盖定位区域

### 1. 结论：不一定能覆盖

边长为 D 的等边三角形，区域直径为 D，最小外接圆半径为

```
R_min = D/√3 > D/2
```

所以任何直径为 D 的圆都无法覆盖该三角形。该反例也能由楔形交会形成：在每条边的延长线上、越过一个端点足够远处放置检测点，让一条楔形边界沿该边指向三角形，另一条边界向内部旋转 2°；检测点足够远时整个三角形都落在楔形内，三个楔形各提供一条三角形边界，它们的交就是该三角形。整体缩放可适配场景的长度尺度。

相反，矩形可以被以其对角线为直径的圆覆盖。因此结论是**不一定能覆盖**，而不是一定不能覆盖。

### 2. 给定区域时的直接判定

取一对最远点 a,b，距离为 D。若半径为 D/2 的圆包含它们，则圆心必须是 c=(a+b)/2：由

```
D = ‖a−b‖ ≤ ‖a−c‖ + ‖c−b‖ ≤ D
```

等号成立迫使 a,b 成为直径端点。于是只需检查

```
max_i ‖v_i − c‖ ≤ D/2
```

圆盘为凸集，包含所有顶点就包含整个多边形。若有顶点超出，则不存在其他圆心能使同直径圆覆盖该区域，判定即为「否」。单点单独按半径为零处理。

**术语口径**：本问输出的圆一律是「以区域直径为直径的同直径圆」，半径即 D/2，不称其为最小外接圆（MEC），也不输出 MEC 符号。上式的判定与「R_min ≤ D/2」等价，论文只保留一种表述。

### 3. MEC 的正确位置

本问**不需要计算通用最小外接圆**即可完成回答。MEC 只在两处出现：

- 等边三角形反例的解析验证：`R_min = D/√3 ≈ 11.547 m > D/2 = 10 m`；
- 后续小问若要在保证清除的位置选点，可计算最小外接圆中心 c\* 与半径 R_min；仅凭 D ≤ 40 m 不能保证存在这样的清除点。
