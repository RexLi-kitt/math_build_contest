# C+ 模型：C/B 原点观测门控

## 一句话

C+ 在原点完成第一次全频道扫描后，根据实际发现数量选择剩余搜索路线：原点零发现时
使用 B 的 27 站边界友好路线，否则使用 C 的 29 站高效路线。门控不改变定位、清除和
提前停止规则。

## 门控规则

```text
原点发现源数 == 0  → B
原点发现源数 >= 1  → C
```

原点零发现可能由源离中心较远、接收半径较小或定向源朝外造成。这些条件恰好对应 C
已知的压力弱点。B 与 C 都从原点开始，因此完成原点扫描后再选路线没有额外探测点。

模型只根据已经取得的观测选择完整的认证站点集合，不会用概率推断频道不存在，也不会
跳过所选路线的必要站点；只有发现 16 个不同频道后，才使用题目给出的源数量上限提前
结束搜索。

## 阈值筛选

在独立于最终批次的 100 局正常、100 局最小接收半径、100 局边界随机朝向和100局
边界朝外场景中比较阈值 0、1、2、3。提高结果为：

- 压力场景中四个阈值都会选择 B，性能相同；
- 正常场景中阈值越高，误切到 B 的案例越多；
- 阈值 0 在正常 100 局中与 C 完全相同，在边界朝外 100 局中中中中与 B 完全相同。

因此冻结阈值 0，不再使用筛选案例调参。

## 全新种子独立验证

| 场景 | B | C | **C+** | C+ 选择 |
|---|---:|---:|---:|---|
| 正常 500 局，均值 s/源 | 672.62 | **616.29** | **616.29** | C |
| 正常 500 局，P95 | 868.84 | **806.85** | **806.85** | C |
| 全部 R=1000，200 局 | 658.16 | 613.30 | **612.99** | 挡门控 |
| 边界+随机波束，200 局 | **567.87** | 577.11 | **567.87** | B |
| 边界+朝外波束，200 局 | **567.62** | 765.62 | **567.62** | B |
| 全清除率 | 100% | 100% | **100%** | 共 1100 局 |

配对差：

- 正常组 C+−B = −56.33 s/源，95% CI [−61.11, −51.56]；
- 边界随机组 C+−C = −9.24，95% CI [−19.24, +0.77]；
- 边界朝外组 C+−C = −198.00，95% CI [−212.99, −183.01]。

边界随机组相对 C 的均值改善在本批次置信区间包含 0；C+ 在该组采用 B 的事实和具体
性能可复现，但不能宣称对所有边界随机分布都显著优于 C。

## 文件

- `cplus_gate_agent.py`：出货代理 `CPlusAgent`，并保留阈值 0—3 的筛选类；
- `run_cplus_gate_screen.py`：四个阈值的场景筛选；
- `run_cplus_validation.py`：B、C、C+ 的独立配验证；
- `results/cplus_gate_screen/`：阈值筛选结果；
- `results/cplus_holdout/`：全新种子 1100 局验证结果。
