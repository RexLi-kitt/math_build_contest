# 第四问定向源离线实验

本目录在第三问 J+ 的基础上加入定向干扰源，用同一批随机案例比较：

- `Q3_Jplus_direct`：直接沿用第三问的原点加七点环搜索；
- `Q4_triangular_900`：用边长 900 米的等边三角网格进行多方位搜索。

定向源的有效覆盖范围为发射中轴两侧各 90 度。两种策略都不把 `no_signal`
直接解释为源不在检测点附近，避免把位于定向源背面的观测错误地当作距离排除证据。

运行：

```powershell
python q4_experiment.py --cases 30 --seed 20260912 --output results/run_30
```

结果目录包含逐案例表、汇总指标和第一局动作日志。该程序是离线策略筛选工具，不能替代官方模拟器演练或生成正式测试日志。

## 已完成验证

运行命令：

```powershell
python q4_experiment.py --cases 100 --seed 20260912 --output results/validation100_v4
```

100 个配对案例中，直接迁移第三问 J+ 的全清除率为 10%，定向源清除率为
69.22%；三角网格方案的全清除率和定向源清除率均为 100%。三角网格方案平均
每源耗时 903.11 秒，说明它适合作为第四问保底基线，但扫描开销仍有较大优化空间。
