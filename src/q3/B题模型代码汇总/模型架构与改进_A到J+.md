# B 题模型架构与改进（A–J+）

本文档给出 B 题三层模型的结构、A 到 J+ 的每个模型架构、演进关系、关键公式、实验数据与负面消融。第三问结果来自不读取真值的离线模拟器；正式测试需经官方接口复核。所有第三问数字为统一第二问口径后的**三种子 × 1000 局配对结果**（种子 55021/24119/90317），机制分解为三种子 × 200 局（112358/271828/314159），最终模型为 `JPlusAgent`（J+）。

## 1. 总体分层与代码映射

| 层 | 职责 | 代码位置 |
|---|---|---|
| 几何基础层（问题一） | 方位误差带、半平面求交、定位区域与直径 | `第二问/src/q1/localization.py` |
| 单源决策层（问题二） | 物理可行域、最小包围圆、四指标第二检测点、接收概率 | `第二问/src/q2/q1_q2_bridge.py`、`solve_q2.py`、`boundary_tests.py` |
| 多源调度层（问题三） | 覆盖发现、信息测量、清除调度、路线规划 | `第三问策略对比/baseline_core.py`、`feasible_region.py`、`strategies.py` |
| 运行环境层 | 离线模拟器、官方 HTTP 接口 | `第三问策略对比/baseline_core.py`、`模拟器与官方接口/` |

第三问的 `feasible_region.py` 是第二问几何模块的在线复用版本：外多边形由任务圆域（外接 72 边形）、历次 ±1° 方位带和 1500 m 测向上界逐次裁剪得到；清除判定使用保守最小包围圆。

```

        ├── CPlusAgent（C+：完成时间 + 顺便测量）
        │   ├── CoverageIntegratedAgent（F：覆盖协同 + 低绕路插入）
        │   │   └── RollingCoverageAgent（G：逐动作滚动）
        │   │       ├── RingOptimizedAgent（I：覆盖环 1150 m）
        │   │       │   └── JCompactRingAgent（J：七点环 R=1000，k–R 联合设计）
        │   │       │       ├── JPlusAgent（J+：测量并入清除路径）★ 最终模型
        │   │       │       └── AblationRing8Agent（8 点环 R=950，负消融）
        │   │       ├── TaskSchedulingAgent（H：动作点路由 + 不抢占，负消融）
        │   │       └── RotatedRingAblationAgent（覆盖环旋转，负消融）

        └──（C 即 Q2FourMetricAgent 本身）
```

## 2. 公共基础设施

1. **离线模拟器 `OfflineSimulator`**：按题设实现移动 5 m/s、频道切换 1 s、检测 5 s、光学定位 3 s（≤20 m）、清除 2 s（≤20 m）、≤5 m 直接清除、±1° 测向误差散列、接收半径 1000–1500 m。策略层不读取真实源位置。
2. **频道状态 `ChannelState`**：观测列表、检测点、无信号点、发现/清除/穷尽标志、主动尝试次数、清除失败点。
3. **信念区域 `feasible_region.py`**：`build_region_cached`（按观测历史记忆化）、`_clip`/`_clip_bearing`/`_clip_outer_circle`（Sutherland–Hodgman 裁剪，72 面切向预缓存）、`minimum_enclosing_circle`（洗牌顺序缓存）、`predicted_circle`（预测加入新方位后的包围圆）、`reception_probabilities`（接收半径条件概率）。
4. **选点接口 `SelectionDecision`**：位置、得分、四项指标原始值（q_geo、p_rec、travel_s、r_pred_m），供插入与缩短判断复用。
5. **路由 `_two_opt_route` / `_route_anchor`**：开放路径最近邻初解 + 2-opt 与 Or-opt 交替优化；`_route_anchor` 为可覆写钩子（H 用它改为动作点）。
6. **七点覆盖与旋转 `search_points` / `_set_ring_rotation`**：原点 + 半径 `search_ring_r` 的六等角点；旋转保证不变，供消融使用。

## 3. 每个模型的架构

### A：最小二乘交点 + D-opt（`SevenPointAgent`，`baseline_core.py`）

- **覆盖层**：`search_points` = 原点 + 1250 m 六边形；`search()` 在每个覆盖点对未发现频道测量，已发现频道方位不足 3 条时顺手补测；`_opportunistic_clear` 以 250 m 绕路预算顺路清除。
- **信念层**：`_belief_samples` 单方位时沿射线生成离散候选；多方位时在最小二乘交点附近生成样本。
- **选点层**：`_fim` + `_information_rate`；对每个信念样本计算加入候选方位后 Fisher 信息矩阵 `log det` 增益，除以移动 + 动作时间。
- **清除层**：`_least_squares_intersection` 求交点；失败后用 `_clear_neighborhood` 的 ±15 m 十字兜底；20 m 内清除。
- **调度层**：`_two_opt_route` 排序剩余目标；`localize_and_clear` 逐个源完成。
- **运行**：`run()` = `enter → search → 逐源定位清除 → exit`。
- **定位**：旧基线，平均值不慢但失败清除多、尾部差。

### B：可行域 + 最小包围圆 + D-opt（`FeasibleRegionAgent`）

- **信念层（替换 A）**：`_snapshot → build_region_cached`，用多边形裁剪得到保守可行域并取最小包围圆；`_belief_samples` 改为区域采样。
- **清除层（替换规则）**：`_clear_decision` 仅当包围圆半径 ≤ 19.75 m（20 m 光学半径留 0.25 m 余量）时前往圆心；`localize_and_clear` 改为“可清则清，否则继续补测”。
- **调度层**：`_target_anchor` 改用圆心；`_opportunistic_clear` 基于圆心与绕路预算。
- **选点层**：仍为 A 的 D-opt（继承）。
- **定位**：消除失败清除；代价是严格清除条件需要更多补测。

### C：第二问四指标选点（`Q2FourMetricAgent`）

- **选点层（替换 D-opt，统一第二问口径）**：
  - `_coarse_candidates`：以**首次检测站**为原点、距离 `(200, 600, 1000, 1400, 1800)` m、60° 步长的粗网格；
  - `_score_pool`：在当前池内对四项指标做 min-max 归一化并加权求和：
    `J = w1·Q_geo + w2·P_rec − w3·T_move − w4·R_pred`；
  - 取粗网格前二名，`_refine_candidates` 在距离 ±100 m、方位 ±10° 邻域加密；
  - **只在加密集上重新归一化与评分**，`_select_from_scored` 用 range-based R_good 带（峰值的 10% 带，负分时仍有效）选移动最小者；
  - `_next_measurement_point` 组合上述流程，先做近平行方位的退化恢复。
- **指标定义**：`q_geo` 对全部历史站取 `max sin²`；`p_rec` 为保证接收样本比例；`r_pred` 为预测包围圆半径的**均值**；第三指标 `T_move` 为到候选点的移动时间。
- **权重**：`(0.35, 0.30, 0.15, 0.20)`（第二问示例值，用于结构对比）。
- **定位**：作为第三问对第二问选点模型的直接调用。

### C+：完成时间 + 顺便测量（`CPlusAgent`）

- **选点层（改第三指标）**：`_raw_metrics` 中第三项改为**预计完成时间**：当前位置 → 候选检测点 → 预测圆心的路程 ÷ 速度 + 6 s；并限制相对直接前往当前圆圆心的额外路程 ≤ 250 m。
- **共观测层（新增）**：到达主动检测点后，对其它已发现未清除频道计算保证接收比例与交会质量，`p_rec ≥ 0.60` 且单位时间价值 ≥ 0.035 时顺便测量，最多 3 个，不增加移动。
- **清除层**：`localize_and_clear` = 清除判定 → 选点测量 → 共观测循环。
- **权重**：`(0.25, 0.25, 0.35, 0.15)`（第三问多源在线目标筛选值）。
- **定位**：显著改善均值与尾部，零失败清除。

### D：混合信念 + 风险约束滚动（`HybridBeliefRollingAgent`）

- **信念层（加权）**：样本权重由固定未知接收半径在 [1000, 1500] m 上的条件可行区间给出；`no_signal` 对 1000 m 内确定排除、1000–1500 m 只降低概率。
- **选点层（风险约束）**：`_raw_metrics` 全部按信念权重计算接收概率，主动感知要求 `p_rec ≥ 0.60`；预测半径用带权 90% 分位（本模型保留风险口径）。
- **调度层（滚动）**：`run()` 在搜索后逐动作滚动，路线引导（2-opt/Or-opt）只执行首个动作，更新后重规划。
- **定位**：总体框架实验组，与 C+ 基本持平。

### F：覆盖协同（`CoverageIntegratedAgent`）

- **覆盖层（新增调度）**：`_coverage_order` 枚举未访问覆盖点的开放路径，代价 = 覆盖路程 + 终点到最近已发现目标锚点的衔接距离。
- **插入层（新增）**：`_insertion_before` 对每个未清除频道调用第二问选点，若插入当前位置与下一覆盖点之间的额外路程 ≤ 140 m 则执行，每局最多 8 次。
- **共观测预算**：`search()` 中随未清除源数把附加测量名额由 3 次阶梯提高到最多 6 次；未发现频道仍在每个必要覆盖点检测以维持发现保证。
- **其余**：清除判定、四指标、权重、选点内核全部继承 C+。
- **定位**：覆盖路径与信息任务首次结合的“粗调度”。

### G：逐动作滚动（`RollingCoverageAgent`）

- **调度层（替换 F 的清除方式）**：`run()` 中搜索阶段与 F 完全相同（`search_end_time_s` 一致）；清除阶段每步用 `_two_opt_route` 重排全部未清除源，只执行首个目标的一次动作（清除或一次测量），更新信念后立即重规划。
- **其余**：全部继承 F。
- **定位**：增益全部来自清除调度，因果干净。

### H：滚动任务调度（`TaskSchedulingAgent`，负消融）

- **路由层（改节点）**：`_route_anchor` 改为“可清频道取圆心，否则取第二问推荐检测点”，用真实动作点建路。
- **调度层（不抢占）**：`run()` 维护 sticky 目标；测量后若包围圆半径 ≤ 60 m，则保持该源为第一优先直到清除或穷尽。
- **结果**：20 局配对整体 6/20 胜、平均 +18.8 s；只改动作点 9/20 胜、−3.2 s；只改不抢占 2/20 胜、+11.5 s。均未通过验证。
- **机制解释**：清除段实际路径与同一停靠序列的近优回路之比仅 1.043（中位 1.014），该诊断支持优先考察停靠点集合，但相对于启发式近优参考的比值不能证明全局最优或排除顺序改进。

### I：覆盖环半径优化（`RingOptimizedAgent`）★

- **覆盖层（改几何）**：`search_ring_r = 1150 m`。最坏覆盖闭式：
  `d(R) = sqrt(1800² + R² − 2·1800·R·cos30°)`，要求 `d(R) ≤ 1000`，解得 `R ≥ 1123 m`；R=1150 时 d=988.5 m（留 11.5 m 余量），巡回由 7500 m 降到 6900 m。
- **其余**：全部继承 G（第二问口径选点 + 覆盖协同 + 逐动作滚动）。
- **定位**：相对 G 的 600 局机制回测省 9.1 s/源、3000 局省 10.0 s/源；后被 J 超越。

### J：覆盖环点数—半径联合设计（`JCompactRingAgent`）

- **覆盖层（改几何）**：环点数与半径一起优化。一般化最坏覆盖
  `d_k(R) = sqrt(1800² + R² − 2·1800·R·cos(π/k))`，由 `d_k(R) ≤ 1000` 得
  `R_min(k) = 1800cos(π/k) − sqrt(3240000cos²(π/k) − 2240000)`：
  R_min(6)=1122.9、R_min(7)=997.2、R_min(8)=938.1 m。取 k=7、R=1000（最坏覆盖 998.25 m，余量 1.75 m），巡回 6900→6207 m。
实际 I/J/八点环（R=1150/1000/950 m）的固定开放路线约为 6900/6207/6040 m，纯移动分别节省约 138.7/33.4 s/局。扫描次数随频道发现过程变化，不是每加一点固定增加 60 s。600 局配对中 J 比 I 快 8.0 s/源、比八点环快 1.81 s/源，支持已测试方案中选择 k=7、R=1000，不构成全局最优证明。
- **其余**：全部继承 I（选点、清除、共观测、滚动）。
- **定位**：三种子 ×1000 配对省 7.8 s/源（95% CI [7.1, 8.4]），达到 298.2 s/源；负消融 `Ablation_ring8_950` 慢 1.81 s/源。详见 `第三问模型改进机制报告/05_I到J机制回测报告.md`。

### J+：测量调度修正（`JPlusAgent`）★

- **调度层（改测量位置）**：撤销扫描期低绕行插点（`_insertion_before` 直接返回空），第二问推荐测量点全部并入滚动清除路径顺路完成；四指标权重再标定为等权 `(0.25, 0.25, 0.25, 0.25)`，环点共观测预算下限 3→5（原点仍为 3）。
- **机制**：F 的插点机制来自 R=1250 几何；紧凑环下环已靠近源，绕出去测量反而增加绕路，而现有滚动路径是启发式路线，未证明近最优；600 局中搜索后移动增加 5.8 s/源，但搜索移动减少 7.1 s/源，合计移动仍减少 1.3 s/源。搜索结束提前约 149.8 s/局。
- **定位**：**最终模型**，三种子 ×1000 配对相对 J 再省 4.7 s/源（95% CI [4.2, 5.2]），达到 **293.5 s/源**；累计相对 I 省 12.5 s/源，3000 局全清除。详见 `第三问模型改进机制报告/06_J到J+机制回测报告.md`。

## 4. 统一决策管线

```
环境层   OfflineSimulator（移动/切换/检测/光学/清除计时，±1° 误差）
   │
覆盖发现层 ── A/B：七点扫描 1250 m
           └─ F/G/H/I：覆盖协同（顺序枚举 + 低绕路插入 + 顺便测量）
              I：覆盖环 1150 m（闭式保证）
   │
信念层   ── A：射线/交点离散样本
           └─ B~I：可行域 + 最小包围圆（D：带权概率信念）
   │
选点层   ── A/B：D-opt 信息率
           └─ C~I：第二问四指标（第二问候选集口径 + r_pred 均值）
              C+：第三指标换成完成时间，增加共观测
              D：带权接收概率 + 风险分位
   │
清除层   ── A：最小二乘交点 + 十字兜底
           └─ B~I：包围圆半径 ≤ 19.75 m 时圆心清除
   │
调度层   ── A~F：逐源 2-opt/Or-opt
           └─ D/G/H/I：逐动作滚动重规划
   │
运行层   run() = enter → search → 清除调度 → exit
```

## 6. 负面消融汇总

| 消融 | 机制 | 结果 |
|---|---|---|
| 边际插入 | 收缩量/额外路程阈值替代固定预算 | 每局 +86.9 s |

## 8. 结论边界

- 第三问选点直接调用第二问模型（候选集与 r_pred 均一致），仅保留有明确动机的在线推广：多站几何、完成时间第三指标、range-based R_good 带与紧凑环权重再标定。

- 覆盖保证依赖任务圆半径 1800 m 与接收半径下界 1000 m；J+ 的 R=1000 余量 1.75 m，若官方环境对边界更敏感可取 1005~1010 m 并重跑回归。
- 所有结果来自离线模拟器，不替代官方演练；正式测试前须通过官方接口复核并保留回退策略（I）。
