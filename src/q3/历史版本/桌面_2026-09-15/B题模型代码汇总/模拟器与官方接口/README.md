# B题机器狗离线模拟器

这是一个不依赖官方模拟器的离线演练项目。它按照 B 题的动作、计时、测向误差、频道和接收半径规则随机生成全向干扰源，用来检验“七点覆盖搜索 + 第二问主动选点 + 动态定位清除”的策略。

它不能生成官方正式测试日志，也不能替代官方演练。正式测试前，应把同一策略层接到官方 `http://127.0.0.1:2026` 接口再次验证。

## 运行

需要 Python 3.10 或更新版本；不需要安装第三方库。

```powershell
python b_robot_offline.py --cases 30 --seed 2026
```

常用参数：

```powershell
# 单个案例，并打印每一步动作
python b_robot_offline.py --cases 1 --seed 7 --verbose

# 固定生成 16 个干扰源
python b_robot_offline.py --cases 20 --seed 2026 --sources 16

# 指定结果目录
python b_robot_offline.py --cases 50 --seed 2026 --output results
```

运行后会在 `results/` 写出：

- `case_results.csv`：每局清除数、总时间、移动与检测等时间构成；
- `summary.json`：总体统计；
- `actions_case_001.json`：第一局的完整动作日志。

## 官方模拟器的接口通路测试

`official_smoketest.py` 只检查 Python 能否连接到已经启动的官方模拟器。它不保存参赛队号；运行时必须显式传入：

```powershell
python official_smoketest.py --robot-id "你的参赛队号"
```

如在模拟器设置中改过端口，例如 2027，则追加：

```powershell
python official_smoketest.py --robot-id "你的参赛队号" --base-url http://127.0.0.1:2027
```

运行前必须先在官方模拟器中登录、启动“问题3演练测试”，并等待倒计时结束和接口就绪。该脚本会依次执行一次 `/enter`、原点一次 `/measure` 和 `/exit`，因此一次运行就是一局短演练，不能在正式测试中用于调试。

## 运行完整的官方演练基线

接口通路测试成功后，可以在**新开的一局问题3演练测试**中运行：

```powershell
python official_baseline_runner.py --robot-id "你的参赛队号" --verbose
```

该程序会执行七点覆盖搜索、逐频道多站检测、批量交会、临时启发式补测及动态清除顺序，并把本程序的动作日志写入 `official_logs/baseline_actions.json`。它使用的是临时启发式，尚未接入问题2正式模型；只可用来检验接口闭环和收集演练结果，不能直接用于正式测试。

## 实现的策略

1. 在原点和半径 1250 m 的六个等角点扫描所有未知频道。七点对目标区域的最坏覆盖距离为 951.6 m（出现在圆域边界上相邻环点之间的中点），小于 1000 m 的有效接收半径下界，保证每个源至少被一个搜索点检测到；比 1500 m 环少走 1500 m。
2. 停靠点补测是“免费”的：已发现频道只要方位不足 3 条，就在当前搜索点顺手补一条（每次仅 6 秒），而不是留到清除阶段专程绕路（每次上百秒移动）。
3. 两条交角不小于 30° 的方位线交会误差约 20-35 m，配合 ±15 m 十字兜底与 20 m 光学定位半径，通常足以直接清除；清除失败仅损失 3 秒，并自动回退继续补方位。搜索途中对估计点在 500 m 内的目标顺路清除。
4. 对仍观测不足的频道，使用首次方位的离散候选源点，以方位 Fisher 信息矩阵的 D-opt 对数行列式增益除以预计动作时间，为下一观测点打分；清除顺序采用最近邻初解和 2-opt+Or-opt 交替局部优化（Or-opt 段搬移可把被甩到路线末尾的簇内点搬回簇内，这是纯 2-opt 反转邻域覆盖不到的移动），减少跨区折返。

离线 300 局演练（seed 2026）：全清除率 100%，平均虚拟时间 4382.0 s、中位数 4335.9 s、最差 6401.5 s；合入前（1500 m 环、阈值补测、纯 2-opt）的同口径基线为 5510 s / 5454 s / 7563 s，平均提速约 20%。官方演练一次实测：10 源案例 10/10 清除、10 次清除全部一次成功、总虚拟时间 3843 s。

第 4 步是为让离线演练能独立运行而写的第三问近似评分，**不是你们的问题 2 代码，也没有经过问题 2 的验证**。待问题 2 的选点函数跑通后，应将该函数替换为你们的正式接口，再重新完成全部演练对比。

离线模拟器中的随机源点仅用于测试，策略代码不读取源点真值。

## 与官方模拟器的差异

本项目实现的是同一题意下的可控离线环境。官方模拟器有真实的账户、测试窗口、HTTP 幂等请求、加密日志与正式案例规则；这些不能由本项目模拟或替代。
