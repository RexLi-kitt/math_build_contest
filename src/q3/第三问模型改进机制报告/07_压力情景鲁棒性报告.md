# 07 I/J/J+ 压力情景鲁棒性报告

## 1. 实验目的与模型冻结说明

本实验检验 I、J、J+ 在非标准源点分布、最小接收半径、系统测角偏差与最大任务负载下的可靠性与效率，回答三个问题：

1. 紧凑覆盖环在边界和最小接收半径下是否仍能发现全部源；
2. J+ 相对 J 的收益是否能跨压力情景保持；
3. 若性能下降，主要损失发生在移动、检测切换还是定位清除阶段。

**模型在实验前冻结**：I（`RingOptimizedAgent`，六点环 R=1150）、J（`JCompactRingAgent`，七点环 R=1000）、J+（`JPlusAgent`，J＋撤销扫描期插点＋等权＋共观测预算 5）在本次实验中未做任何修改；结果不用于调参。代码哈希记录于 `results/stress_robustness/experiment_manifest.json`：

```
strategies.py      931f0506124288ad
baseline_core.py   9076d3cee178f408
feasible_region.py c5d984e950066fc1
stress_robustness.py 69fd904fa3b35dfd
```

实验规模：7 情景 × 3 个全新随机种子（104729、130363、155921）× 每个种子 200 局 × 3 模型 = **12600 次模型运行**，墙钟 680 s。同一情景、种子、局号下三模型共享完全相同的源点、频道、接收半径与误差场（严格配对）。

## 2. S0–S6 场景定义

| 情景 | 生成规则 |
|---|---|
| S0 基准 | 沿用模拟器原始生成：面积均匀、10–16 源、接收半径 U(1000,1500)、独立 ±1° 误差（与前序实验对照） |
| S1 边界 | 源位于 r=1799/1800，方位为 J 七点环扇区角平分线 ±{0°, ±0.2°, ±1°}；每局从中抽 10–16 个 |
| S2 最小半径 | 面积均匀、10–16 源，所有接收半径固定 1000 m |
| S3 系统偏差 | 面积均匀；每局全部方向测量共享同一偏差，前 100 局 +1°、后 100 局 −1°（不允许正负抵消） |
| S4 聚集 | 2–3 个簇，簇心间距 ≥700 m，源相对簇心 ≤150 m，10–16 源 |
| S5 满载 | 每局固定 16 源，其余同基准 |
| S6 复合 | 16 源、r∈[1750,1800]、落在 2–3 个相邻最坏扇区、接收半径固定 1000 m、共享 ±1° 系统偏差 |

## 5. 配对收益

| 情景 | I→J 平均（95% CI） | J→J+ 平均（95% CI） | I→J+ 平均（95% CI） |
|---|---:|---:|---:|
| S0 基准 | +5.66 [4.24, 7.06] | +5.62 [4.52, 6.68] | +11.28 [9.94, 12.61] |
| S1 边界 | +25.53 [23.93, 27.08] | +7.59 [6.98, 8.20] | +33.12 [31.58, 34.63] |
| S2 最小半径 | +5.50 [3.72, 7.28] | +5.10 [3.98, 6.24] | +10.60 [8.89, 12.33] |
| S3 系统偏差 | +8.74 [7.24, 10.25] | +6.54 [5.49, 7.59] | +15.28 [13.85, 16.75] |
| S4 聚集 | +7.36 [5.66, 9.05] | +6.82 [5.45, 8.16] | +14.18 [12.51, 15.87] |
| S5 满载 | +5.50 [3.95, 7.03] | +5.24 [4.14, 6.37] | +10.74 [9.18, 12.30] |
| S6 复合 | **−27.49 [−29.73, −25.26]** | **+7.59 [6.29, 8.92]** | **−19.90 [−22.04, −17.79]** |

- **J→J+ 在全部 7 个情景为正**，收益 5.1~7.6 s/源，CI 完全大于 0，三种子方向一致：J+ 的测量调度修正在压力情景下保持有效。
- I→J 在 S0–S5 为正（5.5~25.5 s/源），其中 S1 边界收益最大（+25.5）；**S6 复合情景转负（−27.5）**。
- S6 的机制解释：源全部贴边（r∈[1750,1800]），六点环 R=1150 距源约 650 m，而七点环 R=1000 距源约 800 m，I 的清除腿更短（移动 138.1 vs J 153.3 s/源），且 I 的停靠点更少（扫描 52.5 vs 64.8）。J+ 在 S6 中仍比 J 快 7.6 s/源，但两者都慢于 I。该结果表明覆盖环最优半径与源径向分布有关：J+ 为均匀分布调优，在极端边界聚集下不是最快，但“J+ 优于 J”的机制不受影响。

## 6. 失败案例诊断

首轮运行曾把 180 个案例标记为“搜索结束时未发现”，定位后确认是**统计口径伪失败**而非覆盖失效：

- 机理：最后一批源在搜索的最后一个停靠点被检测，动作时间戳按 6 位小数取整，可能比未取整的 `search_end` 大 2×10⁻⁷ s，被 “> search_end + 1e-9” 的严格比较误判；
- 处理：容差改为 0.01 s 后复跑，未发现、未发现源、覆盖漏检全部归零；修复只改度量代码（`stress_robustness.py`），三个模型一字未动；
- 复核：S1/S6 边界源均在解析最坏覆盖点附近被检测（J/J+ 最坏覆盖 998.25 m，余量 1.75 m；I 988.5 m，余量 11.5 m），未出现真实漏检。

修正后 `failure_cases.json` 为空。首轮 180 个案例的完整动作日志保留在首轮输出中，仅作口径排查记录，不作为模型失败。

## 8. 适用边界

- 全部结果来自离线模拟器（策略层不读取真值）；正式测试前须经官方接口复核，S3/S6 的系统偏差与边界构造尤其需要在线验证，回退顺序为 I → J+。
- S3/S6 的“系统偏差”实现为同一局内所有方向测量共享同一 ±1° 偏差（不允许独立噪声抵消），是对题设“系统测角偏差”的强解释；若官方误差模型不同，结论需重跑。
- S6 暴露的环半径—源分布耦合是后续可研究方向（按已发现源的径向分布自适应环半径），当前 J+ 保持固定 R=1000，未受影响的使用场景为均匀/聚集/满载等常规分布。
- 图件：`outputs/q3/figures/Q3压力情景鲁棒性汇总表`、`Q3压力情景平均与P95耗时`、`Q3压力情景配对收益森林图`（png+pdf）；数据：`results/stress_robustness/`。

## 结论（对应三个实验问题）

1. **紧凑覆盖环在边界与最小接收半径下仍能发现全部源**：S1/S2/S6 共 1800 局，未发现与覆盖漏检均为 0，七点环 1.75 m 最坏覆盖余量在边界构造下经数值验证。
2. **J+ 在所有压力情景保持 100% 全清除**：12600 次运行零硬约束失败，P95 全部不劣于 J 且改善 1.8~13.0 s/源。
3. **J+ 相对 J 的收益跨情景稳定**：7 个情景平均 +5.1~+7.6 s/源，95% CI 全部大于 0，三种子方向一致。
4. **性能下降时的成本主要来自移动**：S1 边界 I→J 移动减少 31.1 s/源、检测增加 5.5 s/源，净收益由移动主导；S6 反向时同样是 I 的移动更短（−15.2 s/源）决定排序。
5. **仍需官方接口复核的场景**：S3 系统偏差与 S6 复合极端；其余场景可在论文中作为离线压力证据使用。
