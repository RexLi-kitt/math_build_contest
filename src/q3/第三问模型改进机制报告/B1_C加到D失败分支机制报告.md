# C+ 到 D：失败探索分支机制报告

## 分支结论

D 是一条**动机合理、局部有效、整体不值得保留**的探索分支。600 个配对案例中，D 将平均耗时从 **337.0** 降至 **334.8 s/源**，均值改善 **2.2 s/源（0.6%）**，但 D 只在 278/600 局更快，C+ 反而在 322/600 局更快。

2×2 消融进一步表明，D 的概率/风险信念层没有带来收益：单独启用时比 C+ **慢 1.3 s/源**；叠加到逐动作滚动后又使模型 **慢 1.4 s/源**。D 的全部正收益来自“每执行一个动作就重新排序”的滚动调度，单独加入这一机制可以改善 **3.6 s/源**，而完整 D 只保留其中 2.2 s/源。

因此，D 不进入 `C → C+ → F → G → I` 主线。它在拓扑图中应画为从 C+ 分出的虚线失败分支，其中“逐动作滚动”被保留下来，后来在 F 的覆盖融合基础上形成 G；“概率信念 + R90 风险选点”被放弃。

## 1. 为什么当时会做 D

C+ 已经解决了选点只看当前移动距离和停靠点复用不足的问题，但仍存在三个看起来合理的改进空间：

1. **可行域样本没有区分概率高低。**C+ 对保守可行域内的样本近似等权处理；有噪声方位和无信号记录时，不同位置实际不应具有相同可信度。
2. **接收判断过于硬。**C+ 主要用保证接收样本计算候选点价值，容易忽略接收半径不确定性；用平滑接收概率替代硬阈值，理论上能减少落在接收边界外的无效测量。
3. **按频道完成后再换目标可能利用不了新信息。**一次测量会改变该频道的信念状态，也可能通过共观测改变其他频道状态。每次动作后重排剩余任务，理论上比一次决定一个频道并处理到底更符合在线多源决策。

所以 D 并不是没有依据的堆架构。它尝试把 C+ 从“集合约束下的启发式选点”推进到“集合保证 + 概率权重 + 风险尾部 + 滚动调度”的统一在线框架。

## 2. 这么做的合理性是什么

| D 的设计 | 理论依据 | 原本希望改善的指标 | 合理性判断 |
|---|---|---|---|
| 对可行域样本赋概率权重 | 含噪方位下，满足约束只表示可能，并不表示等可能 | 减少无效测量、降低检测与切换时间 | 合理，但必须证明权重与真实误差分布匹配 |
| 用期望接收概率筛选候选点 | 接收半径在 1000–1500 m 间变化，硬阈值不能表达边界风险 | 提高测量成功率、减少重复定位 | 合理，但当前概率模型可能过度平滑或校准不足 |
| 用预测半径 R90 代替均值 | 平均半径可能掩盖少量很差的后验情形 | 改善 P95、减少尾部困难案例 | 合理的风险控制思想，但可能为尾部付出过多平均成本 |
| 每个动作后重新规划剩余频道 | 新测量会更新状态，旧路线可能失效 | 降低移动时间和折返 | 已由消融证实有效，后来被 G 继承 |

这条路线的关键问题不在理论方向，而在当前任务中“概率建模带来的决策改善”是否大于额外保守性与额外测量。实验表明答案是否定的。

## 3. 七项指标回测

| 指标 | C+ | D | C+−D | 解释 |
|---|---:|---:|---:|---|
| 全清除率 | 100% | 100% | 0.0 pp | 可靠性没有提升空间 |
| 平均总耗时（s/源） | 337.0 | 334.8 | **+2.2** | 只有 0.6% 的小幅均值收益 |
| P95 总耗时（s/源） | 422.0 | 418.3 | **+3.7** | 风险尾部略有改善 |
| 移动时间（s/源） | 265.3 | 261.4 | **+3.9** | 滚动重排减少移动 |
| 检测与切换时间（s/源） | 66.7 | 68.4 | **-1.7** | D 额外付出 1.7 s/源信息成本 |
| 最后源首次发现时间（s/源） | 148.1 | 148.1 | 0.0 | 搜索阶段完全相同 |
| 搜索后剩余定位负担 | 82.7% | 82.7% | 0.0 pp | D 没有处理覆盖阶段的瓶颈 |

时间分解给出完整机制：D 节省 **3.9 s/源移动时间**，却增加 **1.7 s/源检测与切换时间**，净收益只剩 **2.2 s/源**。D 的搜索阶段与 C+ 共用同一实现，所以最后源发现时间、搜索结束时间和剩余定位负担在全部 600 个配对案例中逐案相同。

## 4. 2×2 消融：真正有效的是滚动，不是概率信念

| 实验组 | 概率/R90 信念 | 逐动作滚动 | 平均 s/源 | P95 s/源 | 相对 C+ |
|---|---|---|---:|---:|---:|
| C+ | 无 | 无 | 337.0 | 422.0 | — |
| C+ + 滚动 | 无 | 有 | **333.4** | **418.2** | **改善 3.6** |
| D 信念 + 原批处理 | 有 | 无 | 338.3 | 423.4 | 恶化 1.3 |
| 完整 D | 有 | 有 | 334.8 | 418.3 | 改善 2.2 |

概率/R90 信念在两种调度背景下方向一致：相对 C+ 批处理恶化 1.3 s/源，相对 C+ 滚动恶化 1.4 s/源。逐动作滚动在两种信念背景下都能减少移动，但概率信念增加主动测量和共观测，将部分移动收益抵消。完整 D 平均每源测量 11.47 次，高于 C+ 的 11.17 次；共观测也由 0.50 增至 1.03 次。

## 5. 三个种子与不稳定性

| 种子 | C+（s/源） | D（s/源） | C+−D | D 更快 | C+ 更快 |
|---:|---:|---:|---:|---:|---:|
| 112358 | 334.8 | 332.0 | +2.8 | 89/200 | 111/200 |
| 271828 | 337.9 | 335.6 | +2.3 | 91/200 | 109/200 |
| 314159 | 338.3 | 336.9 | +1.5 | 98/200 | 102/200 |

600 局配对均值差的近似 95% 置信区间为 **[1.3, 3.0] s/源**。D 的平均值略优，但赢局数少于 C+，说明收益依赖少数改善幅度较大的案例，不构成稳定逐局优势。既有 seed 55021 的 1000 局也只从 336.2 改善至 334.5 s/源，量级同样很小。

## 6. 逐项假设证据表

| 假设 | 观测证据 | 状态 |
|---|---|---|
| 逐动作滚动可以减少旧路线失效造成的移动 | 只加滚动后移动和总耗时下降，总耗时改善 3.6 s/源 | **已验证** |
| 概率加权可以减少无效测量 | 单独加入概率/R90 信念后检测与总耗时均增加 | **已验证（假设不成立）** |
| R90 风险指标可以独立改善尾部 | 信念批处理的 P95 从 422.0 恶化到 423.4；滚动背景下完整 D 的 P95 也略差于无概率信念的滚动组 | **已验证（假设不成立）** |
| 完整 D 可以改善覆盖阶段遗留的定位负担 | C+ 与 D 的最后发现时间和搜索后定位负担逐案完全相同 | **已验证（假设不成立）** |
| 当前概率/R90 层失败是因为过度保守并诱发额外测量 | D 比无概率信念的滚动组多测量、更多共观测，检测成本更高；但尚未把概率权重、接收概率和 R90 分别拆开 | **部分支持** |
| 重新校准概率模型或风险分位数能够挽救该路线 | 现有实验没有单独扫描概率温度、接收曲线和分位数 | **待验证，但不影响本版放弃 D** |

证据表将“机制无效”和“失败原因尚未完全拆清”分开：我们已经能判断当前 D 不应保留，但不能据此断言所有概率信念模型在该题中都无效。

## 7. 为什么最终放弃 D

| 放弃标准 | 实验事实 | 判断 |
|---|---|---|
| 核心新增机制应有独立正贡献 | 概率/R90 信念在批处理和滚动背景下分别恶化 1.3、1.4 s/源 | **不满足** |
| 复杂度增加应换来足够大的总体收益 | 完整 D 只改善 2.2 s/源，且 C+ 赢局更多 | **不满足** |
| 应改善目标瓶颈 | 搜索后定位负担仍为 82.7%，与 C+ 完全相同 | **不满足** |
| 应优于更简单的后续方案 | 同一批案例 F 为 321.9 s/源，比 D 快 **12.9 s/源**；P95 也低 15.6 s/源 | **不满足** |
| 应保持与第二问模型的可解释连接 | D 新增概率权重、接收概率、R90 和滚动层，难以逐项对应第二问四指标 | **叙述成本过高** |

D 被放弃的原因不是它完全无效，而是它没有证明最复杂的新增部分有效。保留完整 D 会产生错误的论文叙述：看起来是“混合信念地图带来提升”，实际提升来自滚动调度；概率信念反而削弱了滚动收益。

## 8. 失败分支中保留了什么

- **保留逐动作滚动思想。**该模块独立改善 3.6 s/源，具有清楚的移动时间路径。它没有随 D 一起丢弃，而是在 F 解决覆盖阶段问题后形成 `F → G`。
- **放弃概率加权和 R90 选点。**当前实现没有独立收益，也没有改善发现阶段或搜索后定位负担。
- **保留失败实验作为负消融。**它证明“更完整的概率模型”不必然优于保守可行域与简单均值，避免论文把架构复杂度误当成贡献。

拓扑图建议画成：

```text
C → C+ → F → G → I
      └── D（混合信念 + 滚动，失败分支）
          └── 滚动思想被 G 吸收
```

## 9. 可直接用于论文的失败尝试表述

在 C+ 基础上，我们曾尝试构建集合—概率混合信念模型 D：对可行域样本赋予概率权重，以期望接收概率约束主动测量点，以预测定位半径的 90% 分位控制尾部风险，并在每次测量或清除后重新规划剩余任务。该设计能够表达测向噪声、接收不确定性和在线状态更新，因而具有明确的决策理论动机。

配对消融表明，D 相对 C+ 仅降低 2.2 s/源，且优势全部来自逐动作滚动调度；概率/R90 信念在批处理和滚动背景下分别使耗时增加 1.3 和 1.4 s/源。D 也未改变最后源发现时间及搜索后剩余定位负担，并被覆盖任务融合模型 F 进一步领先 12.9 s/源。因此，我们放弃 D 的完整架构，只保留经验证有效的滚动调度思想，并在 F 的基础上形成后续模型 G。
