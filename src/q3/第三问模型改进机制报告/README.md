# 第三问模型改进机制报告

本文件夹按第三问最终模型主线保存每一步改进的机制报告：

`C → C+ → F → G → I → J → J+`（最终模型 J+）

每份报告统一回答四个问题：

1. 上一模型存在哪个可量化的不足；
2. 新模型修改了什么；
3. 哪些指标按理论预期发生变化；
4. 配对实验和消融实验是否支持机制解释。

## 统一七项指标

1. 全清除率；
2. 平均每源总耗时；
3. P95 每源总耗时；
4. 每源移动时间；
5. 每源检测与频道切换时间；
6. 最后一个源首次发现时间；
7. 搜索结束后的剩余定位负担。

总耗时用于判断模型是否更优，其余指标用于解释收益来源。未达到全清除的实验组不与全清除模型直接比较速度。
