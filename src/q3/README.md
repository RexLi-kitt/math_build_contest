# 第三问工作区

本目录集中保存第三问的模型代码、离线验证工具和论文机制报告。

## 目录分工

- `B题模型代码汇总/第三问策略对比/`：第三问模型与对照实验的主目录，包含 C、C+、D、F、G、H、I 及负消融模型、诊断脚本和原始结果。
- `B题模型代码汇总/模拟器与官方接口/`：当前正式接口入口。提交或演练前从这里运行 `official_strategy_runner.py`。
- `B题机器狗离线模拟器/`：独立离线模拟器包，用于复现实验和检查接口行为。
- `第三问模型改进机制报告/`：面向论文写作的主线机制报告，按 `C → C+ → F → G → I` 排列，另含 `C+ → D` 失败分支。

## 当前基准结论

论文主线采用 `C → C+ → F → G → I`，最终策略为 `I_ring_optimized`。D 是从 C+ 分出的失败探索；H 及其他边际版本保留为负消融，不进入主线。

代码汇总中的 `模拟器与官方接口` 与独立的 `B题机器狗离线模拟器` 保留了少量同名文件。这是为了让两个交付包都能独立运行，并非两套不同算法。若修改正式接口，以代码汇总中的版本为准，并同步检查独立模拟器。

诊断目录中的报告是脚本生成物；论文引用和人工维护以 `第三问模型改进机制报告/` 中的版本为准。`results/` 下的逐局数据和日志属于实验依据，不按冗余文件清理。

目前结论来自离线模拟与配对实验。正式提交前仍需用官方接口做协议和时限验证，不能把离线全清除率表述为官方实测结果。
