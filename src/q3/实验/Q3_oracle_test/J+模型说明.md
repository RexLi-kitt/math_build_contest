# J+ 模型说明（最终版）

J+ = J + 测量调度修正。相对 J 只改两处，都在"测量放在哪里做"：

1. **扫描期不再插点**（`_insertion_before` 关闭）。覆盖环只做：到 8 个停靠点（原点 + 7 环点）→ 扫描未发现频道 → 停靠点共观测 → 顺路清除。第二问推荐测量点全部留到清除阶段，在滚动的清除路径上顺路完成。
2. **四指标权重再标定**为等权 `(0.25, 0.25, 0.25, 0.25)`，停靠点附加共观测预算 3 → 5。

原因：R=1000 的紧凑环已经离源很近，扫描期绕出去做一次测量比"留到清除路径顺路做"更贵；旧插点机制是 R=1250 几何下的产物。选点内核、19.75 m 清除规则、逐动作滚动、覆盖环本身全部继承 J。

代码：`model_jplus.py` 的 `JPlusAgent`（相对实验版只把恒为空的插点搜索短路，决策逐位一致）。

## 3. 收益分解（每源，seed 55021）

```
I  → J ：搜索移动 −9.7（环 6900→6207 m）＋ 清除移动 −2.9 ＋ 扫描 +4.8 = −7.8
J  → J+：搜索移动 −6.9（撤插点）    ＋ 清除移动 +5.5 ＋ 扫描 −3.6 = −5.0
I  → J+：搜索移动 −16.9           ＋ 清除移动 +3.1 ＋ 扫描 +1.2 = −12.6
```

清除段移动只比同起点完美信息 TSP 多约 5%，说明剩余差距主要是保证性覆盖扫描，不是路由。

## 6. 结论边界

- 全部为离线模拟器结果，正式测试前须经官方接口复核，保留 I 为回退模型。
- 覆盖保证依赖"接收半径 ≥ 1000 m"，当前最坏覆盖 998.25 m，余量 1.75 m；环境参数变化需按 d_k(R) ≤ 接收下界重算。
- 任何后续改动（如方向 2 的近距第二观测点）应以 J+ 为父模型重新配对回测。
