## Q2 对 Q1 的依赖说明

`q1_q2_bridge.py` 是问题2的几何评价接口。它复用问题1的：

- `bearing_halfplanes`：将两次示向度转为带 ±1° 误差的角度带；
- `intersect_halfplanes`：计算角度带与作业圆域的可行交集；
- `convex_diameter`：输出二次观测后的预测区域直径；
- `diameter_circle_coverage`：输出同直径圆覆盖判定和最小外接圆半径。

问题2从 `(S1, bearing1)` 构造首次候选区 `(5,1500] m × ±1°`，对每个候选 `S2` 枚举该区域的离散代表点；每个代表点均调用问题1求解器后，再以预测最小外接圆半径、区域直径、交会质量、保守接收比例、移动时间和边界风险评分。

真实源坐标仅能用于离线回放验证，不可作为在线策略输入。
