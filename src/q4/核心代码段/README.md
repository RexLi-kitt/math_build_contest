# Q4 核心代码段索引

| 文件 | 对应 V13 模块 | 用途 |
|---|---|---|
| `q4_solver.py` | Q2 主动二测主链 | 以交会几何、定向接收保障和移动代价选择第二检测点，并给出镜像补测点 |
| `q4_risk_belief.py` | Q4 定向风险保障 | 正确处理 `direction / near / no_signal`，避免把定向盲侧误删为无源 |
| `q4_exact_verify.py` | 清除安全保障 | 以 \(\pm1^\circ\) 角度带交集认证清除点；认证失败则给出局部回补网格 |

三份代码均是从 `experiments/run_q4_risk_belief_closed_loop.py` 提取的可读核心片段，用于论文附录、答辩展示或队内分工；正式批量运行仍使用 V13 主程序。

## 供论文手 QQ 转发的文本

> 【Q4 算法思想】以问题二的主动感知选点为主核：首次正测向后，按交会几何、定向条件下接收保障和移动时间选择第二检测点；第四问仅增加方向—位置风险信念、多频道触发调度及认证失败后的局部回补，以保证定向源条件下的完整清除。  
> 【关键词】定向风险闭环（Directional-Risk Closed-Loop, DRCL）；方向—位置联合信念（Direction–Position Joint Belief, DPJB）
