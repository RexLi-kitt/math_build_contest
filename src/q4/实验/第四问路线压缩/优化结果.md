# 第四问认证路线压缩：优化结果

## 结论

**出货冠军 = `CertRouteAgent`（winner_design.json）：27 站、20.4 km 巡游、证书 gap 162.2°，**
**正常 500 局 667.36 s/源（100% 全清除），边界压力 200 局 572.67 s/源（100%）。**

对比现行方案 ShiftB（28 站、26.2 km、756.10 / 702.78）：正常快 **11.7%**、
压力快 **18.5%**；对比报告推荐的 H8（31 站、21.4 km、713.42 / 638.58）：
正常快 6.5%、压力快 10.3%。且证书余量（17.5°）远大于激进版（6.1°）。

设计搜索全程未使用模拟器数据（纯几何：证书 + 巡游长度），两批验证案例
（seed 20260923 正常组、seed 20260924 压力组）对设计完全外样本。

## 方法（可写进论文）

1. **问题转化**：定向源在 x 处可被保证发现 ⟺ 已测站点中距 x ≤ 1000 m 者的
   方位角最大空档 gap(x) ≤ 180°。设计问题 = min 巡游长度 s.t. 全域 gap ≤ 180°。
2. **搜索**：Stage A 随机环形结构（2–4 环）粗筛；Stage B 自由形态迭代局部
   搜索（删站/移站/向路径中点拉直，成本优先过滤）；Stage C 决赛
   `solve_tour(restarts=200)` + 网格与管道云双审计。
3. **审计提速**：numpy 向量化（certfast.py），逐点保守性经 certify.py 全网格
   比对验证（100% 逐点 ≥）；成本模型 `tour/5 + 66×站数`。
4. **证书**：常规细网格（5 m/0.25°）+ 可达边界弧管道云（真实语义），
   另以 certify.py 原版双网格复核，三种分辨率一致。
5. 优化轨迹（成本 s/局）：H8 6323 → 局部搜索 5416–5531 → 冠军 5864（27 站但
   检测成本更低，模拟器实测反而最快）。

## 注意事项

- 以上均为离线模拟器结果，不能替代官方模拟器演练；正式测试前建议先做
  ≥100 局官方演练确认 100% 全清除与平均时间。
- 压力组为本团队自定义对抗场景（接收半径取下界 1000 m、源贴边、中轴朝外），
  官方测试若参数不同，以官方为准。
- 冠军证书 gap 162.2°（余量 17.8°）；如正式环境对覆盖率要求更保守，
  可改用更短的激进版并接受 6.1° 余量，或两者都演练后择优。
