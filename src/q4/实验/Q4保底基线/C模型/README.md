## 一句话

29 站认证路线（18.1 km）配覆盖优先访问顺序，正常 500 局
**625.7 s/源（两个独立种子，100% 全清除）**，比 B+ 快 5% 左右、
比 ShiftB 快 17.3%、比 H8 快 12.4%；全 R=1000 均匀场景快 13%。

## C 与 B+ 的区别

- 站点：C 用 29 站激进设计（18.3 km，证书余量 6.1°）；B+ 用 27 站（20.9 km，
  余量 17.5°）。两者证书都通过网格 + 管道云审计。
- 顺序：均为"覆盖优先"（C 的顺序由联合目标 `tour/5 + 60n + 78×未覆盖和`
  精炼得到）。优化过程见 `迭代记录.md`。
