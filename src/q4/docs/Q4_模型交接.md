# Q4 模型交接说明

## 1. 当前结论：不要重新选模型

第四问已在既有 **V1–V13** 中完成选型，唯一正式模型为：

> **V13：Q2 主动感知驱动的定向风险闭环清除模型**

**不要继续新建 V14 或为了局部指标重写主链。** 当前任务若无用户明确授权，应围绕 V13 做文档完善、图表、官方模拟器复验或论文撰写，而不是继续改模型。

## 2. 不可改变的核心原则

1. **问题二是核心/基座模型。**
   
   首次正测向 \(\rightarrow\) Q2 主动选择第二检测点 \(\rightarrow\) 交会定位 \(\rightarrow\) 清除，是 Q4 的定位主链。

2. **Q4 只做保障，不替代 Q2。**
   
   Q4 增加定向可见性风险、方向—位置联合信念更新、多频道任务调度和清除失败回补；这些模块不能替换 Q2 的主动选点逻辑。

3. **清除完整性优先于速度。**
   
   先看是否全部清除，再比较全任务时间。任何清除率低于统一 8 场景的 96/96 的方案，不得因局部更快而作为正式方案。

4. **不得把模拟器隐藏真值用于策略。**
   
   策略只能读取 `measure`、`clear` 等动作返回；真实源坐标、接收半径和定向朝向只可由本地模拟器内部使用。

5. **`no_signal` 不等于无源。**
   
   对定向源，`no_signal` 仅说明“该位置、该频道、该时刻未产生可接收信号”；它可能是距离不足，也可能处于定向盲侧。

## 3. 正式模型结构

```text
多频道风险覆盖巡检（发现层）
  └─ 某频道首次 direction / near
       └─ Q2 主动二测（定位主核）
            ├─ 几何质量 Q_geo
            ├─ 定向条件下接收保障 P_rec
            └─ 移动代价 T_move
       └─ 两条正测向：角度带交集 / 保守认证 / 试清除
            ├─ /clear 成功：频道完成，不再巡检
            └─ 失败：第三测向 → 保守认证 → 局部网格回补
```

V13 的 Q2 主动二测评分为：

\[
J(s)=0.30Q_{geo}(s)+0.20P_{rec}(s)-0.50T_{move}(s).
\]

候选点采用 600–1100 m 的源距层、150/250/350 m 横向偏移。概率地图分辨率为 **50 m / 10°**。首次 `direction` 后立即主动二测；若二测 `no_signal`，优先执行首测向线的镜像补测；清除失败才进入更昂贵的第三测向和局部回补。

## 4. 已验证结果与可写边界

### 可写的本地回归结论

统一 8 组本地随机测试场景：每组 12 源、20 频道、全向源与定向源混合。

| 指标 | V13 结果 |
|---|---:|
| 清除数 | 96 / 96 |
| 平均全任务虚拟时间 | 10889.649 s |
| 平均单源定位清除时间 | 537.584 s |
| 单源时间标准差 | 161.354 s |
| 固定场景 20260915 清除数 | 12 / 12 |
| 固定场景 20260915 全任务时间 | 10124.851 s |
| 固定场景最快/平均/最慢单源时间 | 179.345 / 463.923 / 1209.639 s |

### 绝对不能写的结论

- 不能写成官方模拟器正式成绩；
- 不能写成官方环境已验证全清除；
- 不能声称理论/全局最优；
- 不能写成“二次测量必然定位并清除”；
- 不能把局部回补或预测交会点当作无条件成功的清除证明。

正式论文建议写法：**“本地规则模拟器回归测试表明，该策略在 8 组混合场景中实现 96/96 清除；官方模拟器结果仍须独立复验。”**

## 5. V1–V13 的取舍结论

| 版本 | 结论 | 原因 |
|---|---|---|
| V1–V5 | 演化基础 | 建立 Q2 交会、模拟器、风险信念、回补与事件触发二测 |
| V6 | 算法主体 | 高分辨率概率地图 + Q2 主链，96/96 |
| V7 | 不采用 | 谨慎服务距离后单源 613.19 s，劣于主方案 |
| V8 | 不采用 | 接收先验加权与高分辨率叠加有交互反效果 |
| V9 | 不采用 | 两环稀疏发现，完整性仅 92.7% |
| V10 | 仅兜底 | 三角覆盖证书强，但总时间约 12186.08 s、单源约 740.40 s |
| V11 | 不采用 | 动态最近邻巡检/任务上限延迟关键发现与局部处理 |
| V12 | 仅消融 | 单源 533.040 s 略快，但总任务 10896.514 s、更不稳定 |
| **V13** | **唯一正式模型** | **96/96、总时间更优、保留 Q2 主核且稳定可复现** |

特别注意：**高分辨率概率地图没有被淘汰，它是 V13 的组成部分。** 被淘汰的是把 Q2 离线的全局粗搜—局部加密候选结构生硬替换到 Q4 定向后验中的尝试，不是高分辨率地图本身。
