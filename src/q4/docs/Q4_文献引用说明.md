# Q4 文献引用说明：V13 的依据、边界与论文写法

## 1. 引用总原则

第四问正式采用 V13“Q2 主动感知驱动的定向风险闭环清除模型”。引用文献的目的不是堆砌算法名称，而是为以下四个可迁移机制提供理论来源：

1. bearing-only / 示向度观测下的主动第二测点选择；
2. 交会几何质量与定位不确定性之间的关系；
3. 多目标“全局发现—局部精定位”的任务分层；
4. 事件触发重规划与定向风险条件下的工程流程。

必须明确：文献中的机器人、鱼类目标、无人机或静态传感器网络与本题机器狗场景并不相同。论文只能表述为“借鉴其机制并完成题设约束下的场景化改造”，不能写成“直接照搬该文算法”。

## 3. 建议放入论文的引用句式

### 3.1 Q2 主动二测（方法建立部分）

> 对于仅能获得示向度的移动观测平台，主动选择下一观测位置能够提高交会构型的信息量并加速定位不确定性收敛[1]。据此，本文以问题二的主动二测为问题四的定位主核；在定向源条件下，进一步将候选点的接收保障与移动代价纳入评分，以避免几何构型优良但处于信号盲侧的无效复测[2]。

### 3.2 几何质量与保守认证（模型推导部分）

> bearing-only 定位精度与观测构型密切相关，交会角接近直角时具有较好的几何精度[3]。因此，设两次正测向的交会角为 \(\gamma\)，以 \(Q_{geo}=\sin^2\gamma\) 评价候选第二测点的几何质量；同时参照 GDOP 对测向站构型敏感性的解释[4]，将 \(\pm1^\circ\) 角度带交集而非单一中心线交点作为最终清除认证依据。

### 3.3 多频道调度与风险回补（模型求解部分）

> 多目标主动定位可采用“全局发现—局部精定位”的分层方式，在发现目标后优先调度其局部搜索，而已完成目标退出后续任务队列[5]。本文将频道视为天然目标标识：风险覆盖巡检用于发现频道，首次正测向后立即触发问题二的主动二测；定位失败时再进入方向—位置联合信念更新与局部回补。

## 5. 不建议作为 V13 主模型引用的文献与原因

| 文献/方向 | 不采用原因 |
|---|---|
| 《基于 PPO 算法的仿生鱼循迹智能控制》 | 与本题的示向度定位、多频道调度和清除约束不直接匹配；无稳定训练环境与对照提升证据 |
| Transformer-based TD3 海流/避障强化学习 | 水动力、流场、连续控制等前提与地面机器狗无线电定位不匹配，复杂度远高于收益 |
| 《无人机无线电监测混合定位算法》 | 核心依赖 RSSI/AOA 混合信息；本题不能引入 RSSI，因此不能作为定位主模型依据 |
| 直接用 PPO / SAC / TD3 / World Model | 当前 V13 已有可解释、可复现且通过 96/96 本地回归的规则主链；没有训练、验证和官方复现实验时不得把强化学习写成创新结果 |

上述材料若被保留，只能用于“相关工作”或“未来可扩展方向”，不能出现在 V13 的模型公式、主要算法流程或主要结果归因中。
